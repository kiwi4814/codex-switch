# Contributing

> Canonical source: [CONTRIBUTING.md](https://github.com/xjoker/codex-switch/blob/master/CONTRIBUTING.md).

Contributions normally target `dev`. Keep each pull request focused, define behavior with a failing test when applicable, run the documented quality gate, update canonical documentation in the same pull request, and state any unverified platform or real-account path.

Never attach credentials, auth files, personal account metadata, or unredacted debug output. Read the full [contribution guidelines](https://github.com/xjoker/codex-switch/blob/master/CONTRIBUTING.md) before opening a pull request.
