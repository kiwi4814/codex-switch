# Feature guide

> Canonical source: [docs/FEATURES.md](https://github.com/xjoker/codex-switch/blob/master/docs/FEATURES.md).

The main workflows are:

- save, import, deduplicate, rename, switch, and recoverably delete account profiles
- inspect main and model-specific quota pools in the CLI or TUI
- select an account with the shared adaptive eligibility and scoring algorithm
- launch Codex with temporary profile staging and automatic restoration
- consume reset cards only after interactive or explicit non-interactive confirmation
- warm inactive quota pools using models discovered from the authenticated service
- prepare future sessions with the Beta daemon on macOS, Linux, and Windows
- update direct installations from verified GitHub Release archives

For behavior boundaries, automation rules, and examples, read the [canonical feature guide](https://github.com/xjoker/codex-switch/blob/master/docs/FEATURES.md).
